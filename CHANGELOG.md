# Changelog

## 1.0.0 (2026-04-01)

### Initial release

- 7-phase conversion pipeline (Discovery, Tokens, Extraction, Generation, Assets, Fonts, Validation)
- Support for all 29 Stitch design system fonts
- Automatic image downloading from Stitch CDN
- ShadCN/UI component mapping with exact style overrides
- Tailwind v3 and v4 support
- Design token extraction (colors, roundness, color mode)
- Visual validation with screenshot comparison
- Dual MCP support (built-in Stitch + davideast/stitch-mcp)
